Key Concepts:

    Camera Model: The camera is modeled with an intrinsic matrix (which describes how 3D world coordinates are projected to 2D image coordinates).

    Ray from Camera: We compute a ray from the camera’s optical center to a point on the image, typically the bottom center of the bounding box in the 2D image.

    Intersection with Ground: The ray intersects the ground at Y=0Y=0, and from this, we compute the distance.

    Distance Calculation: We need to determine the horizontal distance from the camera to the object by using the ray's intersection with the ground.
