\section{Preprocessing}

To utilize the KITTI dataset for our object detection and depth estimation task, we prepared the data by resizing images and converting the annotation format. This step ensures compatibility with the YOLOv11 object detection framework.

\subsection{Directory Structure}
The dataset resides in the \texttt{datasets/KITTI\_Selection} directory, containing:
\begin{itemize}
    \item \texttt{images/}: Original KITTI images in PNG format.
    \item \texttt{labels/}: Corresponding bounding box annotations in KITTI format.
\end{itemize}
Processed data is saved in \texttt{datasets/prepared\_dataset}.

\subsection{Annotation Conversion}
Bounding boxes in the KITTI format are converted to the YOLO format. The YOLO format specifies each bounding box as:
\[
\texttt{class\_id}\ x\_center\ y\_center\ width\ height
\]
where:
\begin{itemize}
    \item \texttt{class\_id}: Numeric identifier for the object class.
    \item \texttt{x\_center, y\_center}: Normalized coordinates of the bounding box center.
    \item \texttt{width, height}: Normalized dimensions of the bounding box.
\end{itemize}

\subsubsection{Implementation}
We mapped object types from the KITTI labels to YOLO classes using a predefined dictionary (\texttt{object\_classes}). KITTI labels not present in this mapping were ignored. The conversion formula for the bounding box coordinates is:
\[
x\_center = \frac{x_{min} + x_{max}}{2 \cdot \texttt{img\_width}},\quad
y\_center = \frac{y_{min} + y_{max}}{2 \cdot \texttt{img\_height}}
\]
\[
width = \frac{x_{max} - x_{min}}{\texttt{img\_width}},\quad
height = \frac{y_{max} - y_{min}}{\texttt{img\_height}}
\]

\subsection{Image Resizing}
To standardize input dimensions for the object detector, all images were resized to \( 1248 \times 512 \) pixels using OpenCV. The resized images were stored in the \texttt{images/} subdirectory of the output path.

The preprocessing script is implemented in Python. Below is the main function for annotation conversion and image resizing:

\subsection{Evaluation Metrics}
To evaluate the quality of predictions, the Intersection over Union (IoU) metric was calculated for each detected bounding box. The IoU is defined as:
\[
\text{IoU} = \frac{\text{Area of Overlap}}{\text{Area of Union}}
\]
where the overlap is the intersection of the predicted and ground truth bounding boxes. The function to calculate IoU is implemented as follows:

\begin{lstlisting}[language=Python, caption=IoU calculation, label=lst:iou]
def calculate_iou(box1, box2):
    x1, y1, x2, y2 = box1
    x1g, y1g, x2g, y2g = box2

    xi1 = max(x1, x1g)
    yi1 = max(y1, y1g)
    xi2 = min(x2, x2g)
    yi2 = min(y2, y2g)

    inter_area = max(0, xi2 - xi1) * max(0, yi2 - yi1)
    box1_area = (x2 - x1) * (y2 - y1)
    box2_area = (x2g - x1g) * (y2g - y1g)
    union_area = box1_area + box2_area - inter_area

    return inter_area / union_area
\end{lstlisting}

\subsection{Distance Estimation}
Using the intrinsic matrix provided in the KITTI dataset, we estimated the horizontal distance to objects based on their bounding box coordinates. The procedure involves:
\begin{enumerate}
    \item Transforming pixel coordinates (bounding box center) to camera coordinates using the intrinsic matrix.
    \item Projecting a ray from the camera through the pixel into the 3D environment.
    \item Intersecting this ray with the ground plane to calculate the distance.
\end{enumerate}

The calculation is described mathematically as follows:
\[
\mathbf{L} = K^{-1} \cdot \mathbf{p}, \quad \mathbf{p} = [x, y, 1]^T
\]
\[
t = \frac{\text{camera height}}{-\text{ray direction}_y}, \quad \text{intersection} = t \cdot \mathbf{L}
\]
The Python implementation is shown below:
\begin{lstlisting}[language=Python, caption=Distance calculation, label=lst:distance]
def calculate_distance_from_bbox(predicted_boxes, img_height, img_width, K, camera_height):
    for box in predicted_boxes:
